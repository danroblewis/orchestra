Experiments

What machines did with the model. An experiment is a copy of the model a machine edits and runs: forward (what a change would do from now), replay (whether an equation explains a past window) or inverse (what would have had to differ for an outcome). A committed experiment is a prediction of a change, judged once the change has run its horizon. Machines make and run them; this page only shows them.
