A machine is anything outside Orchestra that does something: a program, an AI agent, a service, a person. One that runs as several copies is one machine with instances: events from baker/1 are instance 1 of the machine baker. What it publishes, its instances, the metrics it writes and the hand-offs between machines are observed on the bus and in the metrics store; how it is engaged, what it listens for, what kind of thing it is, where its log is and which package it belongs to are what the machine announces about itself when it starts. A package may list a machine before it is first seen (marked unseen); what is observed always wins.
