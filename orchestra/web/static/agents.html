What each agent is, not what it is doing right now (the Dashboard shows that). A role is a prompt plus a grant of tools plus the events or schedule that wake it. Built-in roles ship with Orchestra; custom roles live in the repository under .orchestra/roles/ and are created in conversation with the Supervisor. Open a role to read the prompt it is started with, the exact tools it can call, and when it next wakes.
