Ladder Glossary Research Editor

Every strategy on every ladder case and variant. Pass rate: the share of runs where every true flow was recovered with the right kind and a rate within tolerance, and nothing spurious. Equivalent: the same linear system with a different structure. Recall / precision: true flows found / found flows that are true. Skill@20: the share of the true model's movement over 20 steps the found model predicts (100% = same as the truth; each run clipped at -100%), on the run it saw and on a fresh run. Complexity of a model = flows + the numbers needed to write its rates over the run (each piece of a rate that changes counts, so an inflow in 9 pieces is 9 numbers; plus effects' numbers, co-flows and hidden stocks), counted the same way for the truth and the found model. Extra: found − true, averaged over runs that found a model (hover for where it comes from); × truth: found ÷ true, the geometric mean. Occam score: accuracy discounted by excess complexity, per run fit × parsimony, where fit is 1 for a pass or equivalent, else the share of true numbers right, and parsimony = true ÷ found (at most 1); averaged over the runs it made (error, timeout = 0; not run yet = left out). Like an information criterion it charges for every number beyond what the truth needs: a model twice as complicated as the truth keeps half its credit, one 10% over keeps 91%; being simpler than the truth earns nothing. Long run (both models run free from the start, no re-anchoring, to t = 100,000; per run capped at 100%, a run that diverges counts 100%): err@100k the gap at t = 100,000 as a share of the truth's range; eq err the settled levels' error; τ err the slowest time constant's relative error; diverges the share of runs that run away, die out or are unstable where the truth is not.
