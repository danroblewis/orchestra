## What works
- **Isolated mechanisms are solved one at a time.** Each failure mechanism found on a hard model
  (CLAUDE.md invariant 4) is distilled into a small case, and a specialist passes it. combined2
  combines the specialists and leads on tests, noisy and distilled cases.
- **Physics and particles,** where the data come from a known process: odefit (output error) and
  master_eq (transition probabilities).
- **Large models predict well** with blockwise's shared-sums fit.

## Testing without tokens
- **`scripts/sdlab-daemon.sh`:** start it with `nohup sh scripts/sdlab-daemon.sh >> ~/.sdlab/daemon.log 2>&1 &`. It keeps the server and
  the watcher alive and refreshes long-run and strict verdicts hourly.
- **The watcher** runs every missing or stale test. A strategy's results go stale when its
  directory changes. It skips retired and heavy strategies and cases unless they are named.
- **Commands:**

  | command | what it does |
  |---|---|
  | `uv run sdlab-ladder status` | where every strategy stands |
  | `uv run sdlab-ladder run --strategies S --cases ids` | runs specific tests now |
  | `uv run sdlab-ladder sync --strategies S` | runs what is missing or stale for one strategy |
  | `uv run sdlab-ladder cost --strategies S` | estimates the time to re-test |
  | `uv run sdlab-ladder show CASE --strategy S` | true vs found, part by part |
  | `uv run sdlab-ladder prune --dry-run` | finds results for cases or variants that are gone |

- **Pages:** https://sdlab.dansproject.space/ladder/leaderboard, `/ladder/new`,
  `/ladder/strategy?name=S`, and the Now page's runs panel.
