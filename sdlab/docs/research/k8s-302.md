# Kubernetes rung 3 (case 302), round 1: spurious pieces beat the constrained row

**Status:** round 1 done for cause A (2026-10-20). Code at 8c507a8. Other causes of 302 failures
(held_out, matrix_v2, recession, starved_coflows) are not covered here.

Case 302-k8s-responses-counter: rung 2 (`traffic -> queue -> inflight`) with the completions counted
into `responses_total`, a final stock (a Prometheus counter). Before this round 22 of 49 active
strategies failed counts-short; every other variant passed for all 49 (`store.latest`, 2026-10-20).

## Cause (confirmed)

18 strategies (matrix, blockwise, censored, drifting_drain, hidden_transit, latent_eras, mass_balance,
master_eq, odefit, own_tables, periodic_inflows, shared_noise, symbolic_anchor, unified, numopt_bo/cma/nm/
powell) returned matrix's answer on counts-short: the three true flows within 1.5%, plus
`inflight -> outside 32.2` in 4 pieces (7.6 oracle SE; spurious). The fine PELT pass finds chance pieces
on inflight, a stock with no outside inflow; once the counter's row fixes inflight's drain at 0.4973,
the leftover drain is folded into the pieces and the pieces candidate wins the in-sample judge (0.0461
against 0.0520 for the constant-inflow candidate, which would pass). Not the data's limit: `sdlab-ladder
analyse` rates counts-short achievable (p 1.00), and earned_pieces passed (0.6004 / 0.4978 / 1.002).

Confirmation (in-process, scratch scripts): swapping each strategy's call of the pinned
`identify.identify` for a main line that refits each candidate with earned_pieces' refit made 17 of the
18 pass 302 counts-short (shared_noise has its own vendored main line). The smaller alternative, matrix's
`gate` option (change_price's textbook-price gate on rows with no outside inflow), also passed 302 for 14
of 15 tried, but on matrix's 134-cell paired sample it gained 6 and lost 2 cells, against 24 gained and
0 lost for the earned refit, so the earned refit was taken.

## Change (8c507a8)

- Each strategy's package carries a copy of earned_pieces' refit (`earned.py`, `earned_rows.py`,
  `earned_joint.py`, from 66086e7) and calls `earned.main_line` where it called `identify.identify`: every
  main-line candidate is rebuilt (rows chosen again, pieces kept only where earned, conservation decided
  jointly on the counting likelihood) before the main line's judge. No import across strategies.
- One addition in the copies' `earned_rows.reselect`: pieces found again at the textbook price
  (`pelt`, 2 x log n x the noise variance, starting from the levels' numbers beside the matrix's
  pieces) compete on the same BIC. Without it, a stock whose inflow really changes but which settles
  fast after each change leaves white residuals without pieces, and its drain came out near 0 (an
  integrator): on mass_balance's `one_hidden` the main line went from skill@20 -0.25 to -356; with it,
  a gets its 4 real pieces and skill@20 0.88. On the symbolic_anchor `chain` test it raised the main
  line from 0.885 to 0.99 (earned_pieces alone: 0.376).
- shared_noise: only the row step (`earned_rows.reselect`) before its own `finish`, so its move-or-link
  test and conservation decide as before.
- matrix, latent_eras, mass_balance, periodic_inflows, symbolic_anchor became packages to hold the copy.
- Tests: tests of other strategies that used `load("matrix")` as "the main line" baseline now use the
  pinned `identify.identify` (their statements are about the pinned main line); censored's 216 test no
  longer requires its exact-row rewrite, since the main line finds `1 x r` itself; three mass_balance
  mechanism tests are `xfail(strict=True)` (below).

This is a change inside one fit (each candidate's rows), not a choice between finished models.
