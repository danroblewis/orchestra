## How to work on the models

- **After changing any model:**
  `python3 docs/models/build.py && node docs/models/check.mjs && node docs/models/render.mjs`.
  The user asked for this to be run after every model update.
- **Checks have three kinds:**
  - validity: must pass;
  - requirement: a design target; a gap is reported honestly, never tuned away;
  - info.
- **The SD Lab editor format.** Rate forms: constant, proportional, gap, available, linear (the
  last can read inputs). Effects: table or linear.
  - On a flow with machine time (`work` > 0), an effect changes the machine's **speed**.
  - On a flow without it (environment, or program with `work: 0`), it changes the **rate**.

  So stock-dependent outcomes and routing are parallel no-work flows.
- **Diagrams and charts** are viewed through the `md` viewer (Mermaid 11.4; raw HTML is not
  rendered). Check visual changes with headless Chrome screenshots against port 8799, using a
  `--timeout` (the viewer's live-reload stream keeps the page loading).
- **Every number in the models was hand-written by Claude as an estimate.** Say so; never present
  it as data.
